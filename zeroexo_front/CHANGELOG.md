# Changelog

## [1.2.0] - 2026-08-27

提示词查看器链路画布改版（Plan#47）+ 画布交互打磨与资产边界修复轮。本版核心：提示词从「单图预览」升级为「生成链路忠实还原」的专用只读画布，并完成十余项实测验收修复。

### 提示词查看器改版（Plan#47）
- **Modal 全面放大**：1600 × (100vh−96px)，容纳链路画布与长提示词
- **链路只读画布**：参考图列 → 提示词节点 → 生成图列忠实还原生成链路（仿主画布节点卡 + 贝塞尔连线 + 空态占位）；节点锁定不可移动，视口任意缩放级别可平移 + 缩放（右下角竖排工具条）
- **生成模式落库**：后端 Prompt.generationMode（txt2img/img2img，存量零迁移默认文生图），前端 API/本地库/云同步全链路透传；展示层不提供切换控件，布局恒按图生图式呈现（用户拍板）
- **提示词节点默认收起**：62px 小卡（字数 + 单行摘要），点击展开滚动查看全文，收展不改链路几何；主画布生成面板（NodeGenerateDock）同样默认收起，点细条展开（按节点 key 重挂载防状态串扰）
- **输入/输出/封面标记**：胶片条支持输入↔输出切换 + 设封面；公共提示词图片默认输出；节点右上角详情按钮调起统一资源浏览器（嵌套弹窗层级走 antd 自动升层）
- **交互验收修复**：退出双弹窗（closeIcon 双绑定）、详情弹窗层级（全局 zIndexPopupBase=20000，禁手传小值）、重置图标 Maximize2→Scan 区分全屏、首图不上画布（cover 归入输出列）
- **三档图片契约**：画布节点/堆叠详情自适应预览档（永不主动拉原图），原图只在图片浏览器（后端 ?size=preview 无变体自动回退，存量零迁移）
- **i18n**：zh/en/ja 三语新增 promptChain / 生成模式 / 输入输出标记等键组（含长提示词滚动、点击展开等）
- **后端**：Prisma 迁移 20260827100000_prompt_generation_mode，DTO IsIn 校验 + upsert/update 三处透传；双端 typecheck 零错误

### 画布交互与媒体链路（验收轮 #78/#81/#82）
- **右键菜单简化**：堆叠入口收敛为多选「堆叠所选」一项（移除转入堆叠/生成堆叠节点冗余项）
- **批量下载**：右键「下载所选 N 项」+ 堆叠胶囊批量下载按钮，逐项错峰触发；视频截帧菜单新增下载首帧/尾帧/当前帧图片（截帧管线抽公共）
- **图片节点下载加固**：下载优先经 storageKey 重建（刷新后失效 blob / resources 鉴权链路），可下载判定扩为 content || storageKey，无 mimeType 时扩展名按类型兜底（防 .bin）
- **分镜生成位置契约**：剧本生成分镜改为原位正下方 + 向下堆叠成列，关闭重叠避让、不参考周围节点（推翻范文 auto 排列）

### 资产边界修复（#74/#83）
- **提示词附图不再泄漏进「我的资产」**：移除录入上传链路中的资产库副作用注册，附图仅经 PromptImage(storageKey) 关联提示词，展示走预览档/后端 URL
- **同步链路加固**：资产删除级联同文件孪生记录；幽灵记录（无 cloudId）pull/push 双向按 storageKey 归并，不再重建/复活；upsertAsset 增加 storageKey 收敛，同图重复记录自动收敛为一条

## [1.1.0] - 2026-08-25

画布同步通道革命性收敛 + 协作权限体系重构。本版核心是**通道改进机制**：编辑写路径从「HTTP 双写」收敛为 **Yjs 唯一写主干**，同步带宽与协调开销大幅下降，多人/单机编辑均更流畅。

### 🚀 核心通道改进（画布性能）
- **编辑写路径统一收敛（Yjs 唯一写主干）**：编辑一律写入 Y.Doc（WebSocket CRDT 增量同步），HTTP 全量推送 + version 乐观锁 + 409 冲突重试 + 协作抑制闸 + 防回环旗标整体退役——消除双写协调心智负担与冗余带宽；Yjs 离线时本地 IndexedDB 持久化，重连自动合并
- **冗余推送抑制**：单机编辑且 Yjs 健康连接时不再发全量 HTTP PATCH（仅保留元数据轻量通道 pushProjectMeta：标题/封面/标签）
- **光标广播 rAF 节流**：高频 pointermove 每帧最多合并广播一次，多人协作广播量降 90%+，pointerup 补发最终位置不丢帧
- **落库闭环加固**：storeCanvasDocument 增加 upsert 语义，新画布 Yjs 连接态编辑即时落库（不再等离开页面才补推）
- **断线重连热修**：HocuspocusProviderWebsocket minDelay 对齐，消除间歇性重连失败；播种等待窗口命名化（300ms 本地 / 3s 云端），内容判定语义边界修正

### 协作（权限模型 + 审核制 + 邀请链接化）
- **权限两档重构**：只读 / 可编辑（编辑 = 编辑 + 下载捆绑），joinByInvite 真实授权，只读遮罩阻断画布编辑
- **加入审核制全链路**：待审申请（幂等）、批准 / 拒绝、房主待审红点、关闭房间自动作废申请、offline 旧成员重进转 pending 重新申请（三入口对齐）
- **腾讯云文档式邀请落地页**：对外唯一路径式路由 `/c/<code>` 原生识别、未登录可浏览 + 登录回流自动加入、失效页 / 待审页
- **审核体验闭环**：批准后申请人自动进入画布（画布页 SSE 感知 + 邀请页轮询），批准并发防重（原子翻转，不再重复广播/重复提示）
- **成员语义重构**：移出 = 移出（物理删除 + 权限墙拦截），废除封禁残留死锁；房主成员记录自删守卫
- **基础设施修复**：Redis Pub/Sub 回环双送达（room_closed 重复弹窗）、发起者被误判参与者显示失效视图、被踢成员仍可编辑落库

### Agent 与画布
- 消息渲染重构：回合整块复制、子 Agent 图标去色垂直居中、Clarify/Form/Params/Question/Timeline/Text 块统一规范化
- @ 引用可移除、附件列表化（预览 + 移除）、输入框 8000 字上限 + 实时计数、超长文本先确认再入列
- 全节点读写契约：新增 read_node / storyboard_add_shot 工具，SKILL 契约章节 + 提示词铁律
- 渠道选择器平铺模型列表（dropdown 与提示词输入块统一）

### 体验与适配
- 画布页工具栏移动端适配、参与菜单精简 + 失效协作统一失效页、邀请链接路径式路由
- 章回探测管线增强、i18n 三语同步（zh/en/ja）

## [0.1.0] - 2026-07-19

首次正式发布版本。ZeroExo Canvas 是一个可视化节点编辑器，提供无限画布、节点系统、连线、云同步等核心能力。

### Core
- 无限画布（pan / zoom），支持缩放 25% – 500%
- 节点系统：图片 / 视频 / 音频 / 文本 / 通用节点，可拖拽、缩放、分组、对齐
- 连线系统：贝塞尔曲线，支持选中流动特效（UE5 调试风格）、裁剪（剪刀）
- 视口剔除（Viewport Culling）：仅渲染视口内节点
- LOD 多级细节：满级 / 缩略图级 / 色块级，根据节点屏幕像素宽度自动切换
- 渐进式图片加载：根据视口缩放选择缩略图 / 预览图 / 原图
- 撤销 / 重做（History 插件）
- 多语言（zh / en / ja，react-i18next）
- 主题切换（亮 / 暗）

### Storage & Sync
- CAS（Content Addressable Storage）：基于 SHA-256 哈希去重，storageKey 格式 `resources/{ownerId}/{hash前2位}/{hash}.{ext}`
- 三层存储架构：`resources/`（CAS 媒体）/ `canvases/`（画布快照）/ `logs/`（每日日志）
- Reference counting：Resource 表跟踪引用计数，0 时软删除，7 天后 GC 清理
- 云同步：增量同步本地 ↔ 云端，冲突可视化（保留本地 / 云端）
- 后端资源上传：presign + PUT 直传 MinIO，元数据落库

### UI / UX
- 顶部工具栏：标题、撤销/重做、外观面板、文档、语言、设置、开发日志、Agent
- CanvasControls：左上角竖向控件（缩放、对齐、排列下拉等）
- 节点工具栏：选中节点浮现（复制、删除、替换图片等）
- 音频节点：波形可视化、播放控制、波形数据缓存
- 视频节点：非播放时以 img 替代 video，节省 GPU 解码
- 背景点阵：自适应缩放透明度，低于 25% 隐藏
- 开发日志弹窗：版本号 + 变更列表
