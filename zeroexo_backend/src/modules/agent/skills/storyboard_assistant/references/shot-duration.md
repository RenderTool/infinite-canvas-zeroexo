# 镜头时长参考

> 供 storyboard_assistant 规划镜头时长与逐季拆分。核心规则：单镜头不得超过上限（默认15秒）。

## 镜头时长规则

单个镜头时长不得超过用户设定的上限（默认15秒）。时长可在项目配置中自定义。

按视频总时长采用不同策略：

- **短视频（总时长≤60秒）**：按镜头数量规划，而非机械拆分钟时长
  - 30秒 → 建议3-5个镜头
  - 45秒 → 建议4-6个镜头
  - 60秒 → 建议5-8个镜头
  - 开场镜头建议3-5秒，核心镜头8-12秒
- **标准视频（>60秒）**：默认15秒上限
  - 超过上限的镜头必须拆分为多个子镜头

### 短视频镜头分配原则

1. 开场镜头（前3-5秒）：必须抓住注意力，节奏较快
2. 核心内容镜头：承载主要信息，时长适中（8-12秒）
3. 结尾镜头：收束和CTA，节奏平稳（5-8秒）
4. 最短镜头不低于3秒

## 时间拆分原则（标准视频）

| 原镜头时长 | 拆分建议（默认上限15秒） |
|-----------|-------------------------|
| 15秒以内 | 保持单个镜头 |
| 16-30秒 | 拆分为2个镜头（约8-15秒/个） |
| 31-45秒 | 拆分为3个镜头（约10-15秒/个） |
| 45秒以上 | 拆分为N个镜头（每个≤15秒） |

拆分原则：拆分后每个镜头时长尽可能接近上限，且相邻镜头要有运镜变化。

## 按视频类型的单镜头时长建议

| 视频类型 | 建议单镜头时长 | 说明 |
|---------|---------------|------|
| 快节奏短视频 | 3-8秒 | 抖音/快手风格 |
| 教学讲解 | 8-12秒 | 保持清晰节奏 |
| 剧情分镜 | 5-15秒 | 根据情绪调整 |
| 数据展示 | 10-15秒 | 数据需要时间阅读 |
| 产品演示 | 8-12秒 | 突出关键功能 |

## 生成要求

- 每个镜头 duration 必须在合理范围内（项目默认4-15秒）
- 超过上限的镜头主动拆分，并在描述中体现运镜变化
