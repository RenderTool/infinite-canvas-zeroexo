# 电影级画面布局参考

> 供 storyboard_assistant 为镜头规划这类构图与景别。优先使用经典构图，避免单调。

## 景别系统

| 景别 | 含义 | 用途 |
|------|------|------|
| 远景 (ELS) | 环境>人物 | 开场 establishing |
| 全景 (LS) | 人物全身 | 展示造型 |
| 中景 (MS) | 膝盖以上 | 对话场景 |
| 近景 (MCU) | 胸部以上 | 情绪交流 |
| 特写 (CU) | 肩部以上 | 强调细节 |
| 大特写 (ECU) | 极细节 | 强烈冲击 |

## 构图法则

- **三分法**：3×3网格，重要元素放在交叉点
- **黄金分割**：1:1.618比例，更自然和谐
- **对称构图**：平衡、庄重、仪式感
- **框架式构图**：画中画效果

## 布局方案

- **视觉重心布局**：根据重要性分配画面空间
- **引导线布局**：利用线条引导视线
- **层次布局**：前景、中景、背景构建3D感
- **动态平衡布局**：不对称元素达到平衡

## 景别多样性与节奏

- 同一序列内景别必须有变化（远/全/中/近/特），避免连续同景别
- 开场用全景/远景建立环境，核心信息用中近景/特写强化
- 情绪高潮用特写/大特写

## 生成要求

- 每个镜头明确景别 + 构图方式 + 视觉重心位置
- 全局景别分布保持多样性，突出叙事重点
- 与运镜、光影配合表达情绪
