# 角色/场景/道具提示词质量规范

> 供 storyboard_assistant 生成主体（character/prop/scene）时使用，尤其约束 ai_image 生成主体形象图的质量。

## 核心原则：禁止临时状态词

角色提示词中**禁止**使用描述临时状态的词语（如"微笑""哭泣""愤怒""奔跑"），应使用**描述性外貌特征**和**姿势**替代。

| 禁止（状态词） | 替代（外貌特征/姿势） |
|---------------|----------------------|
| 微笑 | 嘴角自然弧度 |
| 哭泣 | 眼眶微红、眼周泛粉 |
| 愤怒 | 眉骨轮廓加深、下颌线绷紧 |
| 奔跑 | 单脚离地、身体前倾、重心前移 |

## 角色主形象提示词结构

```
主体描述（外貌、衣着、年龄、性别）+ 面部特征（轮廓、五官形状，避免状态词）
+ 风格描述（艺术风格、渲染风格、光线）+ 质量标签（8k/细节丰富）+ 比例参数
```

示例：
```
年轻女性，短发，白色衬衫，面部轮廓清晰，电影风格，电影光效，8k，高质量 --ar 9:16
```

## 分镜角色提示词（与基础角色的区别）

- 基础角色提示词：定义角色固定特征（外貌、默认服饰、风格）
- 分镜角色提示词：描述角色在该分镜的具体状态（表情、姿势、服饰调整）
- 精简原则：只描述该分镜可见的变化，状态相同时标注"同上分镜"

示例：
```
林晓明-分镜1: 疲惫状态，眼圈微暗，白衬衫袖口卷起，领带松散，眉头微皱盯着屏幕，坐姿前倾，办公桌前
```

## 场景提示词结构

```
环境类型 + 时间设定 + 光线氛围 + 色调风格 + 关键元素（3-5个核心视觉元素）
```

示例：
```
场景1-深夜办公室: 室内办公空间，深夜，电脑屏幕冷光+窗外城市灯光，冷蓝色调，办公桌、多显示器、咖啡杯、散落的文件
```

## 道具提示词结构

```
外观描述（形状/颜色/尺寸）+ 材质质感（金属/木材/玻璃）+ 状态特征（全新/陈旧/破损）+ 场景关联
```

示例：
```
道具-咖啡杯: 白色陶瓷马克杯，表面有轻微咖啡渍痕迹，把手一侧有细微裂纹，放置在办公桌右侧
```

## 内容安全

- 角色提示词禁止包含暴力、血腥、恐怖描述
- 冲突/紧张场景用抽象视觉元素替代直接描述

## 生成要求

- 主体形象图（ai_image）严格遵循上述结构
- 禁止输出临时状态词、禁止虚构未生成的 imageStorageKey
