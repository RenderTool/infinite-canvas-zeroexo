# 微表情精准控制参考

> 供 storyboard_assistant 在人物镜头画面描述中融入微表情，提升真实感、去除"AI味"。

## 三要素（融入一段自然语言，不机械拆分）

1. **情绪强度** - 通过词汇选择体现：微弱/轻微/明显/强烈
2. **发生原因** - 自然融入情境（"由于担心数据不够理想"）
3. **时间演变** - 用动态词：逐渐/缓缓/突然/猛然

## 描述公式

```
[情境/原因]，角色[情绪类型]，[时间变化词][具体面部特征]，[整体状态补充]
```

## 正确与错误示例

❌ 机械拆分（禁止）：
```
微表情：紧张（强度3级），因为汇报工作，从平静到紧张用了2秒
```
✅ 自然语言（推荐）：
```
站在会议室门口等待汇报时，他的眉头逐渐紧锁，眼神中透着掩饰不住的不安，嘴角紧抿成一条线，整个人绷得像一张拉满的弓。
```

## 微表情描述词库速查

| 部位 | 情绪 | 描述词汇 |
|------|------|---------|
| 眉 | 困惑 | 眉头紧锁、眉心打结 |
| 眉 | 惊讶 | 眉毛上扬、挑起 |
| 眼 | 开心 | 眼睛发亮、眼角弯起 |
| 眼 | 悲伤 | 眼眶泛红、眼中含泪 |
| 嘴 | 开心 | 嘴角上扬、笑容绽放 |
| 嘴 | 紧张 | 嘴唇紧抿、嘴角绷紧 |
| 整体 | 紧张 | 面部紧绷、肌肉紧绷 |
| 整体 | 放松 | 面容舒展、肌肉松弛 |

## 生成要求

- 特写镜头：详细描述微表情变化
- 近景镜头：描述明显面部表情
- 中景镜头：描述整体神态
- 全景/远景：描述肢体语言和整体状态
- 用动态词汇（逐渐/缓缓），避免笼统与过度堆砌
- 微表情要推动剧情，与情绪一致
