# 组装式提示词细节规则

> 供 storyboard_assistant 在生成每个镜头的 description / promptText / promptEn 时注入细节。
> 核心立场：**你是提示词导演，不是形容词装饰工。敌人是形容词汤**（cinematic/dramatic/masterpiece/8K 对模型毫无信息量）。
> 一切替换为**可观察的物理描述 + 显式约束**。本文件所有规则均落在现有字段内，不新增字段。

## 0. 何时套用

| 场景 | 规则 |
|---|---|
| 生成/刷新镜头描述（description） | 铁律 1-7 全量套用 |
| 组装 promptText / promptEn | 铁律 1-9 + 六层结构 + 句尾截断 |
| 相邻镜头 / 同场景多镜头 | 铁律 6 不变量逐字重复 |
| 分块模式（chunk） | 铁律 6 + 终点态，防跨块漂移 |
| 输出前 | 质量门自检（quality-gate.md） |

## 1. 十一铁律（核心细节）

1. **叙事功能优先**：没有叙事功能的镜头删掉，不优化。
2. **先调度后构图**：先定身体在空间里做什么，再放机位。
3. **每镜头一个主运镜**：「不运镜」（固定/锁定）是合法且常常更好的选择。
4. **每个动作有终点态**：「他转身」不是镜头；「他转身直到侧脸贴上窗边，停住」才是。禁止"正要/准备/即将"过渡态。
5. **写行为不写情绪**：禁止「他很恐惧」，写恐惧在身体上的样子（眼神、呼吸、手）。
6. **连续性靠工程（不变量逐字重复）**：身份/服装/光线方向/年代/地点/场景名称，同场景每条提示词**逐字重复**同一描述句，禁止同义改写。
7. **关键帧是控制点**：视频模型大多只是让静帧动起来。首帧必须含主体，先修静帧描述，再写运动。
8. **匹配模型控制面**：不要向模型要它不暴露的能力（如文生视频无参考图时别写"保持 @图片1 角色一致"）。
9. **负面提示词要指名实例**：只写本镜头真实风险的约束；禁范畴式「no modern objects」——写 no plastic, no wristwatch, no printed logos。
10. **一次只套一个风格镜**：混用两位导演风格必然失控。
11. **回答配得上问题**：该镜头只给该镜头的描述，不扩散。

## 2. 六层结构（promptText 组装骨架）

每镜头 promptText 按以下六层组织（缺层可省略，勿硬凑）：

```
[角色层] @主体名 的[具体动作]，[表情]，[姿态]。（有角色参考图时用 @引用语法）
[场景层] 在 @场景 中，[环境细节]，[时间天气]。
[镜头层] [景别]，镜头[运镜方式+速度+方向]，[机位高度/角度：平视/俯视/仰视]。
[光影层] [光线类型+方向+色温]，[色调]，[氛围风格]。
[音频层] [环境音效]。角色说出 @音频 的对白，口型同步。[配乐描述]。
[约束层] 画面流畅稳定，面部清晰不变形，保持角色一致性，电影级质感。
```

## 3. 角色细节（动作/表情/站位）

- 每个出场角色必须写清：**动作（动词短语，带终点态）+ 表情（可观察的微表情，非情绪词）+ 站位（画面位置，用左/右/中/前景/背景）**。
- 同一镜头最多一个主动作（运动预算）：`1 主体主动作 + 1 机位行为 + 1 环境运动`。动作链超预算 → 建议拆镜。
- 对白镜头：写清**说话者是谁**（谁在说），多人对话拆"说话镜头 + 反应镜头"（一人一镜）。

## 4. 镜头语言细节

- 景别 + 运镜 + **机位角度（平视/俯视/仰视）**三件套必须齐，写入 description/promptText 的镜头层。
- 相邻镜头景别至少差两档（刻意匹配除外）；避免连续 3 个相同景别或同类型运镜。
- 画幅比映射（供 aspectRatio 字段，不改表格列）：特写→1:1、近景→4:3、中近景/中景/中远景/远景/全景→16:9、大全景/航拍→21:9。复合景别取落幅映射。

## 5. 句尾截断铁律

- 提示词超长必须截断时，**只在句尾标记（。！？；）处断开**，禁止逗号/顿号硬断。
- 上限：imagePrompt 动作描述 ≤120 字符，videoPrompt 动作描述 ≤300 字符。

## 6. 负面词两层（写入 promptText/promptEn 的约束层）

1. **通用 18 项**（仅在全文级）：deformation, extra limbs, distorted faces, blurry, watermark, text, logo, low quality, bad anatomy, bad proportions, duplicate, mutilated, out of frame, worst quality, jpeg artifacts, signature, username, low resolution。
2. **本镜专项实例**（更重要）：只列本镜头真实风险，如武打戏写 `no weapon slipping, no limb contortion`，现代戏写 `no wristwatch, no printed logos`。

## 7. 正确与错误示例

❌ 坏（形容词汤）：
```
特写，电影级，老张很恐惧，他看向远方，感人，高质量。
```

✅ 好（可观察 + 终点态 + 三件套 + 不变量）：
```
[角色层] 老张（@老张_ref）眉头紧锁，目光凝住，右手缓缓放下铁叉直到叉尖触地，停住。
[场景层] 在深山茅屋前（晨雾灰白基调，晨光从左侧林隙斜射）。
[镜头层] 特写，固定机位，平视，浅景深。
[光影层] 左侧45°自然逆光，5500K，暖灰调。
[音频层] 远处鸟鸣，风声渐止。
[约束层] 保持老张面容一致，面部清晰不变形，无文字无水印。
```
