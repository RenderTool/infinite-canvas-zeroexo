# 质量门 · 10 分制自检（输出每个镜头前必过）

> 供 storyboard_assistant 在 save_shots / 分块直出 JSON 之前，对每个镜头做 10 项自检。
> **任何一项得 0 分即为不合格，该镜头必须重写后才可输出。总分 < 7 禁止交付。**

## 评分方式

对每个镜头逐项打分：0 分 = 完全违反 / 0.5 分 = 部分满足 / 1 分 = 达标。10 项总分满分 10。

| # | 项 | 自检问题 | 0 分典型 |
|---|-----|---------|---------|
| 1 | 叙事功能 | 这个镜头推动剧情/揭示信息/渲染情绪了吗？ | 无功能废镜（"老张走路"无目的） |
| 2 | 机位 | 景别+运镜+机位角度三件套齐全且唯一吗？ | 无运镜、运镜堆叠（推+环绕+升） |
| 3 | 主动作 | 每个出场角色有具体动作动词吗？ | "他站在那里" |
| 4 | 起终态 | 动作有起点和终点态吗？ | "他转身"无终点；"正在走向"过渡态 |
| 5 | 行为非情绪 | 情绪写在身体上而非贴标签吗？ | "他很恐惧" |
| 6 | 不变量 | 身份/服装/光线/场景描述与同场景其他镜头逐字一致吗？ | 同义改写（"灰衣"vs"灰色外套"） |
| 7 | 负面词实例化 | 负面词是本镜真实风险的实例吗？ | "no modern objects" 范畴式 |
| 8 | 可验证性 | 每一行描述都能在生成结果上被检查吗？ | "保持氛围感""神秘感" |
| 9 | 模型匹配 | 描述未要求模型不具备的能力吗？ | 文生视频要求"保持 @图1 一致" |
| 10 | 无形容词汤 | 无空洞形容词（cinematic/dramatic/8K）堆砌吗？ | "电影级大师之作" |

## 分块模式（chunk）适用

分块直出 JSON 时，同一镜头同样过本表。重点盯 4（起终态）、6（不变量，跨块逐字）、8（可验证性）。

## 修正动作（按优先顺序）

1. 补齐终点态：给每个动作加"直到…停住/到位"
2. 情绪转行为：恐惧→"呼吸加快、指节发白、目光闪躲"
3. 补三件套：无角度→补"平视/俯视/仰视"
4. 不变量对齐：回查同场景已输出镜头，逐字复用身份句
5. 负面词实例化：删范畴词，写真实风险
