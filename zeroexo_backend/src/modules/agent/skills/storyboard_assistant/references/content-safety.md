# 内容安全规范

> 供 storyboard_assistant 生成分镜时使用。所有分镜内容必须适合全年龄段，符合平台社区规范。

## 禁止内容

- **暴力**：身体伤害、击打、流血、武器使用、打斗动作、威胁场景
- **血腥**：血液、开放性伤口、死亡、尸体、丧葬、临终场景
- **恐吓**：过度恐怖的描述

## 替换策略（保持戏剧张力）

当脚本需要表达冲突/紧张/危机时，用抽象视觉元素替代直接暴力描述：

| 原描述 | 替换方案 |
|--------|---------|
| 角色被打倒 | 角色快速后退/身体倾斜失衡 |
| 流血 | 衣物破损、能量消散粒子 |
| 痛苦表情 | 面部模糊、剪影轮廓 |
| 武器指向 | 手势引导、能量光束 |
| 追逐打斗 | 光影追逐、符号对抗 |
| 角色受伤倒地 | 角色坐于破碎地面、周围物体散落 |
| 生死抉择 | 分岔路口、天平倾斜 |
| 激烈对抗 | 色彩对比、光影交错、元素碰撞 |

## 情绪符号化表达

| 情绪 | 符号化方案 |
|------|-----------|
| 愤怒 | 红色色调、尖锐几何形状、火焰光效 |
| 悲伤 | 蓝色色调、下雨效果、倒影 |
| 恐惧 | 阴影、模糊边缘、扭曲空间 |
| 绝望 | 黑暗、孤立元素、空旷场景 |

## 审核清单

生成分镜前检查：
- [ ] 是否有身体伤害/血液/伤口/武器/攻击动作？
- [ ] 是否有死亡/临终/过度恐怖描述？
- [ ] 是否可用隐喻替代？
- [ ] 是否保持了戏剧张力？

## 生成要求

- 优先使用抽象化、符号化、环境叙事表达冲突
- 用音效/BGM补偿视觉冲击
- 不确定时选择更保守的表达
