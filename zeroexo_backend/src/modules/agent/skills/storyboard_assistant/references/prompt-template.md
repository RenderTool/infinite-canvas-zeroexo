# AI 视频生成提示词模板（七段式）

> 供 storyboard_assistant 生成每个镜头的 promptText（中文提词器）与 promptEn（英文提词器）时使用。
> 单镜头提示词需独立、完整、可直接生成视频片段，且相邻镜头在内容与时间上连贯。

## 七段式结构

```text
[主体描述]：详细描述主要角色/物体外观、服装、年龄、体型、表情等。

[场景与氛围]：描述环境、光线、天气、色调、整体风格（电影级/写实/赛博朋克等）。

[动作与情节]：按时间顺序描述该镜头的完整动作流程，口述台词处标注"（角色说：XXX）"或"（旁白响起）"。

[台词与旁白]：精确写出该镜头台词/旁白文字、说话角色、语气、语速、情感。

[镜头语言]：明确镜头运动和剪辑方式（从低机位缓慢推近/360度环绕/快速切镜/长镜头跟随等）。

[音画同步/音频]：描述音效、BGM、以及台词/旁白与画面的同步要求。

[其他控制]：时长（建议15秒以内）、分辨率（1080p或更高）、质量要求（高度逼真，细节丰富，无畸变）。
```

## promptText（中文）输出示例

```text
[主体描述]：中年男性，西装革履，面部线条分明，神情专注。
[场景与氛围]：深夜办公室，窗外城市灯光，冷蓝色调，电影级写实。
[动作与情节]：他缓缓起身走向窗边，望向窗外灯火（旁白响起）。
[台词与旁白]：旁白（低沉男声，语速平缓）："那一刻，他终于看清了这座城市背后的真相。"
[镜头语言]：从低机位缓慢推近，追逐人物的背影。
[音画同步/音频]：低沉的弦乐渐强，旁白在推近时音量渐强，与步伐节奏同步。
[其他控制]：时长8秒，分辨率1080p，高度逼真，细节丰富，无畸变。
```

## 生成要求

- 每个镜头生成独立的提示词，能独立生成视频片段
- 相邻镜头提示词在内容与时间上连贯
- promptText 与 promptEn 结构一致，promptEn 为英文翻译
- 遵循内容安全规范（无暴力/血腥描述）
