# 视频提示词生成模板（双轨制）

> 从分镜字段（Shot）生成视频生成模型可消费的 imagePrompt 和 videoPrompt。
> 参考七段式结构 + waoowaoo 双轨制设计。

## 设计原则

- **imagePrompt**：面向图片生成模型（首帧/尾帧/宫格图），强调静态构图、主体细节、光线与风格
- **videoPrompt**：面向视频生成模型（图生视频/文生视频），强调运镜、动作连贯性、情绪氛围与时间维度

两套提示词共享同一分镜数据源，但输出视角不同。

---

## imagePrompt 句式

```
[主体描述], [场景描述], [动作/姿态], [构图], [光线], [风格], 高质量, 细节丰富, 电影级
```

### 字段映射

| 模板段 | 数据源 | 生成逻辑 |
|--------|--------|---------|
| 主体描述 | entities[].description | 取所有主体描述，用逗号拼接；无主体时从 description 提取前 30 字 |
| 场景描述 | environment | 直接使用；为空则从 description 上下文提取 |
| 动作/姿态 | description | 提取动作部分（剔除场景/情绪描述冗余） |
| 构图 | shotType | 景别描述映射（特写→close-up, 中景→medium shot 等） |
| 光线 | lighting | 直接使用；为空时自动推断（日景→自然光, 夜景→低光） |
| 风格 | - | 固定后缀：电影级, 写实风格, 8K |

### 输出示例

```
一位中年男性西装革履神情专注, 深夜办公室窗外城市灯光, 缓缓起身走向窗边, 中景构图, 冷蓝色调, 电影级, 写实风格, 8K, 高质量, 细节丰富
```

## videoPrompt 句式

```
[运镜指导] [场景氛围] [主体动作] [情绪基调] [时间维度] 高质量, 电影级, 细节丰富, 连贯流畅
```

### 字段映射

| 模板段 | 数据源 | 生成逻辑 |
|--------|--------|---------|
| 运镜指导 | cameraMovement | 直接透传原始文本，不映射（支持组合运镜如"推+摇+移"） |
| 场景氛围 | environment + lighting | 组合环境与光线为氛围描述 |
| 主体动作 | description | 提取核心动作流程，含台词/旁白标注 |
| 情绪基调 | emotion + dialogue | 情绪词 + 台词情绪色彩 |
| 时间维度 | duration | 时长信息，用于控制生成节奏 |

### 输出示例

```
镜头缓缓推近同时向左摇, 深夜办公室冷蓝色调氛围, 中年男性缓缓起身走向窗边望向灯火, 沉思凝重情绪, 8秒时长, 高质量, 电影级, 细节丰富, 连贯流畅
```

## 景别映射表

| 中文景别 | 英文映射 |
|---------|---------|
| 特写 | close-up shot |
| 近景 | medium close-up |
| 中近景 | medium close shot |
| 中景 | medium shot |
| 中远景 | medium long shot |
| 远景 | long shot |
| 大全景 | wide shot |
| 全景 | full shot |

## 运镜处理原则

**不设映射表**，直接透传原始 `cameraMovement` 文本到 prompt 中。

理由：
- 真实电影拍摄中一个镜头可组合多种运镜（如"推+摇+移"、"先推后拉环绕"）
- 固定映射表会丢弃复合运镜信息，限制 AI 发挥
- 视频生成模型（Sora/Runway/Pika）理解自然语言的能力远强于固定术语
- 分镜生成的 `cameraMovement` 字段本身已是自然语言描述（如"镜头缓缓推近，同时向左摇"）
